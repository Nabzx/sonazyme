# The biology, from scratch

Everything in this folder is written for somebody who last did biology at
GCSE, or never did it at all. No prior knowledge, no jargon that is not
explained on the spot. If you can read these eleven pages you can follow every
decision in this repo and answer most questions about it.

Read them in order. Each one is a few minutes.

| 3 | [Denaturing](03-denaturing.md) | why do enzymes stop working when it gets hot? |

Two rules for this folder. Everything here is a simplification, and where a
simplification would mislead, the page says so. Anything stated as a fact
about our specific target carries a source or is marked as an assumption, the
same as everywhere else in the repo.
