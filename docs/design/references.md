# Dashboard references

- Date: 2026-11-14
- Issues: #36, #98, #99, #100, #101

Three references guide the first local build. These are selected design
directions, not a claim of endorsement or a copied interface.

| Reference | Take | Leave |
| --- | --- | --- |
| [Existing Sonazyme hero](../../assets/hero.svg) | Dark cooling infrastructure, restrained green and technical labels | Illustrative envelope values; they are not current target data |
| [NASA Eyes](https://science.nasa.gov/eyes/) | A stable scene with controls, legible labels and clear orientation | Celestial imagery, star fields and automatic orbiting |
| [PDBe structure components](https://www.ebi.ac.uk/pdbe/pdb-component-library/) | A structure viewport with a persistent legend and adjacent evidence | Claims that a simple trace is a full scientific molecular viewer |

Use a near-black surface with fine borders, pale text and a restrained green
navigation accent. Prediction is cyan, active site amber, changed region rose.
These meanings never swap. Unknowns use text labels, not a misleading score.

Use the local system sans-serif and monospace stacks. Reserve large type for
the narrative; keep technical labels compact and readable. Nothing depends on
a font download. Layout must work at laptop and narrow mobile widths.

Motion arrives and settles. Camera movement is manual. The conceptual overhead
sequence has pause, step and replay controls and respects reduced-motion
preferences. No scientific inference is represented by an animation.
