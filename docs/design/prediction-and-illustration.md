| Element | Evidence | Required wording |
| --- | --- | --- |
| Target and envelope | Saved target records | Evidence basis and citation or assumption reason beside each value |
| Parent sequence and site definition | Chassis artefact | Source and the recorded scope; incomplete definitions remain marked incomplete |
| Structure | Supplied prediction artefact | Predicted structure, with model and version |
| Structure trace | Actual coordinate rendering | Alpha-carbon trace; it is not a molecular surface |

| Geometry verdict | Integrity artefact and fixed policy | Geometry filter, not evidence of activity |
| Unfolding depiction | Illustration only | Illustrative; not a temperature-dependent simulation |
| Shortlist | Rank artefact | Recorded shortlist; never invent a winner from an incomplete run |
| Scientist answer | Cited explain artefact | Show its citations and refusal; never substitute authored prose as a model answer |
| Acoustic pulse and clearing patch | Conceptual overhead film | Illustration of intended workflow. No sensor or treatment data |
| Replay | Saved manifest and referenced files | Saved snapshot; show snapshot metadata, not an inferred model run date |

The current run inspector displays only what its saved run supports. A missing
value is missing, not zero. No structure is replaced with a decorative protein.
No score is computed in the browser or API. No change in an illustrative patch
is labelled as measured removal. No Sonazyme wet-lab result exists.
